Cloud environment helpers from onboarding. These use /workspace/ping and
/workspace/.ping-dev paths for the managed development workspace. They are
not production deployment scripts. The cloud environment configuration draft
was saved earlier; this archive does not publish environment settings.

For a different machine install the Go version in source/go.mod and use the
build commands in ICMP-RELEASE.fa.md. Production hosts need only the matching
binary, a private config file, and raw ICMP permissions.
